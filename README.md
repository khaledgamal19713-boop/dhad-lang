# dhad-lang
ضاد — لغة برمجة عربية موحّدة مع محرر ودليل شامل

## مختبر نواة (تكامل أولي)

أُضيفت صفحة `nawa.html` بوصفها طبقة تجريبية فوق محرك ضاد الموجود، وتستخدم مباشرة:
- `front.js`: التحليل الرمزي والنحوي.
- `compiler.js`: تصريف AST إلى Bytecode.
- `vm.js`: تنفيذ Bytecode داخل آلة ضاد الافتراضية.

تتضمن الصفحة توجيهًا محدودًا للطلبات، تشغيل برامج ضاد، ذاكرة خبرة محلية، حفظ مهارات بعد نجاح تنفيذها، واسترجاع المهارات واختبارها. لا تتصل هذه النسخة بنموذج لغوي خارجي، ولا تدّعي تدريب أوزان أو استطلاعًا تلقائيًا للويب.

### التشغيل والاختبار
بعد بناء الموقع، افتح `/nawa.html`. لتشغيل اختبارات تكامل المحرك محليًا:
```bash
npm test
```
